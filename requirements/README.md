## Structure
- `BR/`: Business Requirements (why, who, technology-agnostic business rules).
- `SR/`: System Requirements (how, component boundaries, interfaces, schemas).
- `tasks/`: Atomic implementation tasks (objective, scope, checklist, verification commands).
- `diagrams/`: Architecture and sequence diagrams.
